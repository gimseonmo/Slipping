# 설치 및 실행

## 요구 환경

- macOS
- Microsoft PowerPoint for Mac
- Python 3.11, 3.12 또는 3.13
- Node.js 20 이상
- iPadOS Safari
- MacBook과 iPad가 같은 로컬 Wi-Fi에 연결되어 있어야 합니다.

현재 개발 환경에서는 기본 `python3`가 3.14.2였고, 호환 실행용 `python3.13`도 확인되었습니다. 제공된 스크립트는 3.13, 3.12, 3.11 순서로 자동 선택합니다.

## 설치

```bash
./scripts/setup.sh
```

이 명령은 `.venv`를 만들고 Python 의존성을 설치한 뒤, npm이 있으면 프론트엔드 의존성도 설치합니다.

## 실행

```bash
./scripts/start.sh
```

실행기는 다음 작업을 수행합니다.

1. 가상환경이 없으면 생성합니다.
2. Python 의존성을 설치합니다.
3. FastAPI 서버를 `0.0.0.0:8787`에서 시작합니다.
4. PowerPoint 감시 에이전트를 시작합니다.
5. iPad에서 접속할 로컬 네트워크 URL과 QR 코드를 출력합니다.

종료는 터미널에서 `Ctrl+C`를 누르거나 다음 명령을 사용합니다.

```bash
./scripts/stop.sh
```

## iPad 제스처

노트 읽기 화면에서 좌우로 크게 스와이프하면 PowerPoint 슬라이드쇼가 원격으로 넘어갑니다.

- 왼쪽으로 스와이프: 다음 슬라이드
- 오른쪽으로 스와이프: 이전 슬라이드

이 제스처는 편집 모드에서는 동작하지 않습니다. Safari의 시스템 뒤로가기 제스처와 충돌할 수 있으므로, 화면의 아주 바깥쪽 가장자리보다 노트 영역 안쪽에서 쓸어 넘기는 것이 안정적입니다.

## macOS 권한

PowerPoint 상태 감지를 위해 macOS가 자동화 권한을 요청할 수 있습니다.

- 시스템 설정 > 개인정보 보호 및 보안 > 자동화
- 터미널 또는 사용하는 터미널 앱이 Microsoft PowerPoint와 System Events를 제어하도록 허용

일부 환경에서는 프로세스 감지에 손쉬운 사용 권한이 필요할 수 있습니다.

- 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용
- 터미널 또는 사용하는 터미널 앱 허용

권한이 거부되면 iPad 화면에는 PowerPoint 대기 또는 권한 오류 상태가 표시됩니다.

## 방화벽

iPad가 접속하려면 Mac의 로컬 방화벽이 Python/터미널의 수신 연결을 허용해야 합니다. 공용 네트워크에서는 실행하지 않는 것을 권장합니다.
