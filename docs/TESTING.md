# 테스트

## 자동 테스트

```bash
cd backend
PYTHONPATH=. ../.venv/bin/python -m pytest
```

테스트 범위:

- PPTX 슬라이드 텍스트 추출
- 발표자 노트 XML 추출
- 빈 노트 처리
- 슬라이드 번호 매핑
- 노트 편집과 원본 복원 저장
- 잘못된 슬라이드 번호 거부
- WebSocket 초기 동기화
- 알 수 없는 WebSocket 메시지 오류 처리

## 프론트엔드 빌드 확인

```bash
cd frontend
npm run build
```

## PowerPoint 수동 통합 테스트

이 항목은 실제 macOS PowerPoint와 iPad Safari에서 확인해야 합니다. 현재 Codex 실행 환경에서는 자동화 권한과 프로세스 목록 접근이 제한되어 완료 판정을 할 수 없습니다.

1. 10장 이상 슬라이드가 있는 PPTX를 준비합니다.
2. 일부 슬라이드에는 발표자 노트를 넣고, 일부는 빈 노트로 둡니다.
3. `./scripts/start.sh`를 실행합니다.
4. iPad Safari에서 QR 코드의 주소로 접속합니다.
5. 웹 화면에서 PPTX를 업로드합니다.
6. PowerPoint에서 같은 발표 자료를 열고 슬라이드쇼를 시작합니다.
7. 1번 슬라이드 노트가 iPad에 표시되는지 확인합니다.
8. 다음 슬라이드로 이동했을 때 iPad 노트가 자동 갱신되는지 확인합니다.
9. 이전 슬라이드로 돌아갔을 때도 자동 갱신되는지 확인합니다.
10. iPad 노트 화면에서 왼쪽으로 스와이프했을 때 PowerPoint가 다음 슬라이드로 넘어가는지 확인합니다.
11. iPad 노트 화면에서 오른쪽으로 스와이프했을 때 PowerPoint가 이전 슬라이드로 넘어가는지 확인합니다.
12. 빠르게 여러 장을 넘겨도 최종 슬라이드 번호가 맞는지 확인합니다.
13. iPad Wi-Fi를 잠시 끊었다가 다시 연결했을 때 현재 슬라이드로 재동기화되는지 확인합니다.
14. PowerPoint를 종료했을 때 상태가 `PowerPoint 실행 대기 중`으로 바뀌는지 확인합니다.
15. PowerPoint를 다시 실행하고 슬라이드쇼를 시작했을 때 복구되는지 확인합니다.
16. 발표 중 노트를 편집하고 다른 iPad 또는 브라우저에 변경이 전파되는지 확인합니다.
17. 원본 복원 버튼이 PPTX에서 추출한 노트로 되돌리는지 확인합니다.

## 완료 판정 주의

PowerPoint 자동화는 Office 버전과 macOS 권한 상태에 영향을 받습니다. 위 수동 테스트를 통과하기 전에는 “PowerPoint 연동 완료”로 판단하지 않습니다.
