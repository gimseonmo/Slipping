# 문제 해결

## iPad에서 접속되지 않음

- MacBook과 iPad가 같은 Wi-Fi에 있는지 확인합니다.
- VPN, 게스트 네트워크, 클라이언트 격리 기능이 켜져 있으면 끕니다.
- macOS 방화벽에서 터미널 또는 Python 수신 연결을 허용합니다.
- 터미널에 표시된 주소가 `127.0.0.1`이면 iPad에서 접속할 수 없습니다. 같은 네트워크의 실제 Mac IP 주소를 사용하세요.

## PowerPoint 대기 상태가 계속됨

- Microsoft PowerPoint가 실행 중인지 확인합니다.
- 발표 자료가 열려 있는지 확인합니다.
- 슬라이드쇼를 실제로 시작했는지 확인합니다.
- macOS 자동화 권한에서 터미널이 PowerPoint와 System Events를 제어할 수 있는지 확인합니다.

## 자동화 권한 오류

시스템 설정 > 개인정보 보호 및 보안 > 자동화에서 터미널 앱 권한을 허용합니다. 이미 거부한 적이 있다면 권한 항목을 다시 켜거나 터미널을 재시작합니다.

## PPTX 업로드 실패

- `.pptx` 파일인지 확인합니다.
- 암호화되었거나 손상된 파일은 파싱할 수 없습니다.
- 기본 최대 업로드 크기는 100MB입니다.

## 발표자 노트가 비어 있음

- 실제 PowerPoint 발표자 노트 영역에 텍스트가 있는지 확인합니다.
- 슬라이드 본문에 있는 텍스트는 발표자 노트로 간주하지 않습니다.
- 추출할 수 없는 노트 구조는 빈 노트로 표시되며, 임의의 다른 텍스트로 대체하지 않습니다.

## 프론트엔드가 보이지 않음

백엔드만 실행했고 `frontend/dist`가 없다면 백엔드는 JSON 안내 메시지를 반환합니다. 다음 중 하나를 실행하세요.

```bash
cd frontend
npm run dev
```

또는 빌드 후 백엔드에서 정적 파일을 제공합니다.

```bash
cd frontend
npm run build
```
